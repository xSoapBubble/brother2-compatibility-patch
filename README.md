# Брат 2: Обратно в Америку — патч совместимости

Патч 1.0 для оригинальной русской версии игры с установочного диска,
проверенный на Windows 10 и Windows 11. Цель — исправить ошибки работы
старого движка на современных системах и сохранить исходный вид игры.

**[Скачать готовый патч](https://github.com/xSoapBubble/brother2-compatibility-patch/releases/latest)**
· [Инструкция для игрока](resources/README-RU.txt)
· [Сборка из исходников](docs/BUILD.md)
· [Описание исправлений](docs/FIXES.md)
· [Участие в разработке](CONTRIBUTING.md)

## Установка

Распакуйте ZIP из Releases в отдельную папку, запустите `BrotherPatch.exe`,
выберите папку установленной игры Brother и нажмите «Установить».
Запускайте игру с созданного ярлыка или через `Start-Brother.cmd`.

Проверяется конкретная оригинальная версия. Для другого издания установщик
может отказать до изменения файлов. Сохранения и ресурсы игры в патч не входят.
Резервных копий заменяемых файлов установщик не создаёт.

## Что опубликовано

* Исходники установщика C#, диагностики C#/C и дополнительных звуковых
  компонентов C/C++.
* Python-генераторы всех изменений пяти DLL движка, включая x86-код вставок,
  проверки исходных байтов, адресов и SHA-256.
* Бинарные изменения DLL и описание поддерживаемого оригинала.
* Закреплённые версии инструментов, автоматические проверки и документация.

Исходников оригинального движка у проекта нет. Целые оригинальные DLL,
`brother.exe`, игровые базы, текстуры, звуки и сохранения не распространяются.
Генераторы читают собственную оригинальную установку пользователя и создают
результат в отдельной папке сборки.

## Быстрая сборка

На Windows x64 установите Python 3.10 или новее и Git, затем выполните:

```powershell
git clone https://github.com/xSoapBubble/brother2-compatibility-patch.git
cd brother2-compatibility-patch
python tools/build.py
python tools/check.py
```

Инструменты сборки скачиваются с официальных источников с проверкой
закреплённых SHA-256. Готовый ZIP появится в `build/dist/`.
Оригинальная игра для обычной сборки установщика не нужна.

Чтобы дополнительно создать все пять исправленных DLL из оригиналов и
сравнить изменения с опубликованными:

`D:\Games\Brother-original` ниже — условный пример. Замените его своей папкой
с оригинальной, ещё не исправленной игрой. Для обычной сборки параметр
`--game` не нужен.

```powershell
python tools/build.py --game "D:\Games\Brother-original"
python tools/check.py --game "D:\Games\Brother-original"
```

Точная структура, проверка повторяемости и границы тестов описаны в
[BUILD.md](docs/BUILD.md) и [TESTING.md](docs/TESTING.md).

## Сообщения об ошибках

Укажите версию патча, Windows, издание игры и шаги воспроизведения.
При проблеме диагностика создаёт один `Diagnostics\Brother-Report.zip`.
Подробнее — [DIAGNOSTICS-RU.txt](resources/DIAGNOSTICS-RU.txt).
Отчёт может содержать пути, настройки и фрагменты памяти процесса: проверьте
его содержимое перед размещением в публичном Issue. При необходимости
сначала отправьте только описание и текст ошибки.
