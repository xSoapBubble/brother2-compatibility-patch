# Как предложить исправление

Создайте Fork, отдельную ветку и Pull Request с описанием проблемы, изменения
поведения и выполненных проверок. Для сборки см. [docs/BUILD.md](docs/BUILD.md).

Перед отправкой выполните:

```powershell
python tools/build.py
python tools/check.py
```

Для изменения генераторов движка также выполните проверку с собственной
оригинальной установкой игры. Сохраняйте проверки SHA-256 и исходных байтов,
правильные соглашения вызова x86, релокации и разделение RX/RW.
Опишите новые адреса и смысл изменений в документации.

Генераторы получают байты и возвращают результат; они не должны писать в
папку установленной игры, менять настройки Windows или запускать процессы.
Изменения C/C++/C# компилируются из `src/`; готовые DLL и EXE в Git не добавляются.

Публикуемые бинарные дельты и хеши должны соответствовать генераторам.
Изменение поддерживаемого оригинала или формата патча требует отдельного
обсуждения и тестов отказа на несовместимых файлах.

Не добавляйте оригинальные игровые DLL/ресурсы, сохранения, дампы, токены,
локальные пути и рабочие журналы. CI не должен получать оригинальную игру,
секреты или права публикации для проверки Pull Request.

Отправляя собственный код, вы предлагаете его на условиях MIT этого проекта.
Для стороннего кода укажите источник и совместимую лицензию отдельно.
