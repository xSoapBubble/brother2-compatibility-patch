# Что проверяется

`python tools/check.py` запускает проверки формата дельт, контрольных сумм,
исходного проекта и установщика на собственных синтетических данных.
В тестах CI нет файлов оригинальной игры. Установщик для тестов компилируется
из того же исходника, но с явно отдельным синтетическим payload.

`python tools/check.py --game "папка оригинальной игры"` дополнительно
проверяет все генераторы и установку/повторную установку на изолированной
копии оригинала. Входная игра не изменяется, ярлык на настоящем рабочем столе
не создаётся, игра не запускается.

`python tools/reproducibility.py` проверяет байтовое совпадение двух сборок
из отдельных папок исходников. GitHub Actions выполняет эти доступные без
игры проверки при Push и Pull Request с правами только чтения репозитория.

## Нативные проверки звука

Они требуют Windows с рабочим аудиоустройством и выполняются локально:

```powershell
python tools/build.py --test-components
python tools/check.py --audio
```

Тестовая DLL отсутствует в готовом установщике. Проверки используют собственный
процесс, отдельный временный тестовый ключ настроек и нулевой PCM при native
громкости −10000. Windows default devices и их громкость не меняются.
Реальные отключения оборудования не имитируются этими тестами.

## Ручная регрессия перед релизом

Нужны проверки на установленной игре: повторные сохранения/загрузки, переходы
уровней, меню и инвентарь, камера, оптика, движение и прыжки, Alt+Tab/Alt+F4,
полноэкранные снимки, быстрое сворачивание, регуляторы громкости и физическое
переподключение используемого аудиоустройства.

Не публикуйте личные сохранения и диагностические дампы в исходном дереве.
Отчёт ручной проверки можно приложить к Pull Request текстом.
